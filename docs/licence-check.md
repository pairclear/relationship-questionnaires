# Licence check of validated relationship scales

Checked: **2026-11-26**. Generated from `data/validated-scales.json`.

Licence check of well-known validated relationship questionnaires. We include a scale's items in this repo only if its terms clearly allow anyone to republish, translate and use it, including commercially. None of the scales below met that bar on the check date, so we link to their sources instead of copying items. This is not legal advice; if you plan to use a scale, read its current terms or ask the authors.
